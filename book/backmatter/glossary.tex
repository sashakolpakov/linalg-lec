\chapter{Glossary}
\label{ch:glossary}

\begin{description}
  \item[Vector.] An element of a vector space.
  \item[Vector space.] A set with addition and scalar multiplication satisfying
    the vector-space axioms.
  \item[Subspace.] A subset that is itself a vector space under inherited
    operations.
  \item[Span.] The set of all linear combinations of a list of vectors.
  \item[Basis.] A spanning linearly independent list.
  \item[Kernel.] The set of inputs sent to zero by a linear map.
  \item[Image.] The set of possible outputs of a linear map.
  \item[Rank.] The dimension of the image.
  \item[Inner product.] A rule for measuring lengths and angles.
  \item[Eigenvector.] A nonzero vector whose direction is preserved by a linear
    map.
  \item[SVD.] A factorization $A=U\Sigma V^T$ describing the singular
    directions and singular values of a matrix.
\end{description}
