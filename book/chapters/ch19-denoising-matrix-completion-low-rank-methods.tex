\section{Guiding Question}

How can low-rank structure reveal signal hidden in noise?

\section{Planned Core Ideas}

\begin{itemize}
  \item many signals are approximately low rank;
  \item noise spreads across many singular directions;
  \item truncating the SVD can denoise a matrix;
  \item missing entries can sometimes be predicted from low-rank structure;
  \item modern low-rank methods should be introduced only through accessible
    parameter-count and rank intuition.
\end{itemize}

\section{Planned Python Thread}

Generate low-rank signal plus noise, inspect singular values, truncate the SVD,
and measure reconstruction error.
