\section{Guiding Question}

What information does a linear map keep, and what information does it erase?

\section{Planned Core Ideas}

\begin{itemize}
  \item $\Img A$ is the set of possible outputs;
  \item $\Ker A$ is the set of inputs sent to zero;
  \item rank measures output dimension;
  \item nullity measures lost directions;
  \item rank-nullity links them: $\Rank A+\Nullity A=n$ for
    $A:\R^n\to\R^m$.
\end{itemize}
