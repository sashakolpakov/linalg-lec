\section{Guiding Question}

How much of a matrix can be explained by a small number of directions?

\section{Planned Core Ideas}

\begin{itemize}
  \item SVD writes a matrix as a sum of rank-one pieces;
  \item truncating the SVD gives the best rank-$k$ approximation;
  \item singular values quantify reconstruction error;
  \item PCA is SVD applied to centered data;
  \item low-rank structure explains compression and denoising.
\end{itemize}
