\section{Guiding Question}

What should we do when $Ax=b$ has no exact solution?

\section{Planned Core Ideas}

\begin{itemize}
  \item overdetermined systems are common in data fitting;
  \item least squares minimizes $\norm{Ax-b}$;
  \item polynomial regression is linear algebra after choosing features;
  \item normal equations give $A^TAx=A^Tb$;
  \item validation error reveals underfitting and overfitting.
\end{itemize}

\section{Planned Python Thread}

Build Vandermonde feature matrices with \NumPy, compare normal equations with
\texttt{np.linalg.lstsq}, and observe conditioning as degree grows.
