\section{Guiding Question}

How do we measure length, angle, similarity, and error in a vector space?

\section{Planned Core Ideas}

\begin{itemize}
  \item inner products produce geometry;
  \item norms measure length;
  \item orthogonality means zero inner product;
  \item projections split vectors into explained and residual parts;
  \item cosine similarity is an inner-product idea used in data contexts.
\end{itemize}
