\section{Guiding Question}

How can the same vector or linear map look simple in one coordinate system and
complicated in another?

\section{Planned Core Ideas}

\begin{itemize}
  \item coordinates are descriptions relative to a basis;
  \item a change-of-basis matrix converts one description into another;
  \item the same linear map has related matrices in different bases;
  \item similar matrices represent the same transformation in different
    coordinates;
  \item basis choice affects interpretation and numerical conditioning.
\end{itemize}

\section{Planned Python Thread}

Implement coordinate conversion with \texttt{np.linalg.solve}. Use the
robot-arm trajectory example to compare a monomial basis with a basis whose
parameters have direct physical meaning.
